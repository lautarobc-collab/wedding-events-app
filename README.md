# wedding-events-app

App de planificación de bodas y eventos. Panel privado para gestionar
presupuesto, invitados, tareas y proveedores, más una página pública de RSVP.

- **Empieza aquí**: `docs/SETUP.md` (crear GitHub, Supabase, y arrancar con
  Claude Code en web o local).
- **Diseño y modelo de datos**: `docs/DESIGN.md`.
- **Instrucciones para Claude Code**: `CLAUDE.md` (se lee automáticamente).

Este proyecto no contiene código de ningún competidor — está inspirado en
patrones de UX de herramientas del sector, con implementación 100% original.
